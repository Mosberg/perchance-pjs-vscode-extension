# External code

Complete source (main.pjs + index.html, as served by Perchance) of every external
generator referenced or reused by this project's documentation and examples.
The copy-text-plugin itself has no {import:} dependencies.

| Folder | Generator | Role | URL |
|---|---|---|---|
| animal/ | animal | Random-animal word list. Referenced by the usage example and the output-history example. | https://perchance.org/animal |
| copy-text-plugin-example/ | copy-text-plugin-example | Minimal usage example linked from the plugin page. | https://perchance.org/copy-text-plugin-example |
| copy-text-plugin-example-2/ | copy-text-plugin-example-2 | "Copy a big number" usage example. | https://perchance.org/copy-text-plugin-example-2 |
| output-history-copy-to-clipboard-example/ | output-history-copy-to-clipboard-example | Advanced example: copies a running history log. | https://perchance.org/output-history-copy-to-clipboard-example |

Indirect imports used by the above (public Perchance generators, not vendored here):
- adjective            https://perchance.org/adjective
- simple-gen-footer    https://perchance.org/simple-gen-footer
