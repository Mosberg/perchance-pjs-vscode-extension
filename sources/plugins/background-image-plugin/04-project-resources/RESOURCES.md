# 04-project-resources

**This category is intentionally empty.**

The project defines no assets of its own: no image/audio/video/models, no shader or GLSL files,
no animation clips, no JSON/CSV data files, no prefabs, no templates, no font files, and no UI
resource files.

Everything the plugin renders is produced at runtime as an inline CSS string built inside
`main.pjs`. See `01-internal-code/`.
