# Project resources

**This project has no project resources.**

There is no `src/` tree, no JSON/CSV data files, no prefabs, no templates, and no UI resource bundles. The generator's UI is the static documentation page in `01-internal-code/index.html`. All randomness is generated procedurally at runtime by `Math.random()` inside `main.pjs`; no data files are loaded.

See `../README.md` for the complete inventory.
