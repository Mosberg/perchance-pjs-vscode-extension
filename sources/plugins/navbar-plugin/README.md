# navbar-plugin - complete source & asset package

Everything used by https://perchance.org/navbar-plugin, organized by category.

| Folder | Contents |
|---|---|
| 01-internal-code/ | First-party source: main.pjs (plugin logic) + index.html (docs page) |
| 02-external-code/ | Third-party code embedded/referenced: luxbar CSS, responsive media query, custom-theme template, Open Sans reference |
| 03-third-party-assets/ | Full upstream luxbar repository (MIT) including LICENSE, SCSS sources, built CSS, docs, demo, tests |
| 04-project-resources/ | Project-specific resources: default menu config JSON, reusable menu generator template, options reference |
| 05-build-config/ | Build/config documentation (none exists - this is a native Perchance generator) |

See MANIFEST.md for the byte-level inventory and original locations of every file.
