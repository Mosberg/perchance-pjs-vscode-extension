# External code / dependencies

No {import:...} dependency exists in this generator - it is self-contained.

The platform it runs on is the Perchance engine (https://perchance.org), which is proprietary and is not
redistributed here. See ../README.md section 2 for the list of platform facilities the plugin uses.

referenced-generators/ holds verbatim copies of the generators linked from this plugin's documentation.
They are NOT dependencies - they merely consume this plugin via {import:layout-maker-plugin}.
