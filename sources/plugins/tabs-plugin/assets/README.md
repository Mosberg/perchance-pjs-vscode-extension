# Assets

This project uses **no** static assets.

There are no images, audio, video, fonts, 3D models, shaders, sprites, animations,
JSON data files, prefabs, or templates on disk. Every visual element is produced at
runtime from HTML/CSS/JS:

- Tab styling: CSS string generated by `getCSSString()` in `main.pjs`
- Tab markup: an HTML string returned by the `$output(tabList)` function
- Icons: none (the only image element is an empty `<img src="">` used as a
  load-hack to trigger the tabs initialisation, see `main.pjs`)

So this folder is intentionally empty.
