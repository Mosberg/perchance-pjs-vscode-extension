# 06 — Workspace meta (NOT part of the shipped generator)

`AGENTS.md` is the Perchance platform's agent-instructions document that is placed in the
workspace when an AI helper is editing a generator. It is included here only so the package
is a complete snapshot of the workspace.

It is **not** used by, referenced by, or shipped with the `google-sheets-plugin` generator.
Nothing in this folder affects the live page.
