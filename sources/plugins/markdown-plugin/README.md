## 01 — Internal code

### `01-internal-code/main.pjs`
The generator's Perchance-JS source. Defines the plugin's public API `$output(text, options, callback)`,
the `getMarkedFunction()` loader, the `getMarkedCss()` stylesheet, and the demo `text` list.
The marked 0.5.0 minified library and the GitHub-markdown stylesheet are embedded inline inside
this file, so the plugin is fully self-contained (no runtime CDN fetch).

### `01-internal-code/index.html`
The generator's HTML body: the plugin documentation page, usage example, and page styling.

## 02 — External code

### `02-external-code/marked-0.5.0.min.js`
marked — a markdown parser and compiler. Version 0.5.0, minified build.
Source: https://cdnjs.cloudflare.com/ajax/libs/marked/0.5.0/marked.min.js
Upstream: https://github.com/markedjs/marked
License: MIT
Used by: `getMarkedFunction()` in `main.pjs` (wrapped as `window._____marked123`).

### `02-external-code/markdown-body.css`
The `.markdown-body` stylesheet returned by `getMarkedCss()` in `main.pjs`, extracted verbatim
(10,074 bytes). It is a build of GitHub's markdown CSS/syntax-highlighting theme, and it embeds the
`octicons-link` webfont as a base64 data URI (that font is also provided standalone below).
Upstream: https://github.com/sindresorhus/github-markdown-css
License: MIT

## 04 — Project resources

### `04-project-resources/demo.md`
The demo markdown document that the `text` list in `main.pjs` represents, rendered to plain form.

### `04-project-resources/raw-text-list.txt`
The raw Perchance list text of the `text` list node, captured live from the running generator

## 05 — Build / config

There is no build pipeline, bundler, package manager, or config system: a Perchance generator is
edited and run directly. `main.pjs` and `index.html` are the whole project. The only workspace-level
configuration file is `AGENTS.md` (the AI-helper instructions for this workspace), included here for
completeness in `05-build-config/AGENTS.md`.
