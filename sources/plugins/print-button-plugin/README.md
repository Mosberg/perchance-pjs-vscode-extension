# print-button-plugin — Complete Project Package

A Perchance generator that renders a "Print" button for the page and print-friendly CSS.

* Live generator: https://perchance.org/print-button-plugin

## Layout

- `internal-code/` — the two authored source files (main.pjs, index.html)
- `external-code/` — (empty) no libraries/modules/tools are imported
- `third-party-assets/` — (empty) no third-party assets
- `project-resources/` — (empty) no data/shader/audio/UI resource files
- `build-config/` — (empty) no build pipeline or config
- `ALL_SOURCE.md` — every file reproduced in full, organised by category
- `MANIFEST.json` — machine-readable inventory

See ALL_SOURCE.md for the complete source of every file, plus a description of the
platform-provided runtime dependencies.
