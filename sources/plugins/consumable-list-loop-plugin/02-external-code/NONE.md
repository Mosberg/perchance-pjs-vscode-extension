# External code: NONE

This project has no external code. `main.pjs` contains no `{import:...}`
statements, so no Perchance plugins are pulled in. There are no npm/ESM imports,
no CDN `<script src>` tags, no `fetch()` calls, and no vendored third-party
libraries.

The only executable code in the project is `../01-internal-code/main.pjs`
(pure JS inside Perchance pjs syntax) and the inline `<style>` block in
`../01-internal-code/index.html`.
