Notes:

- The 4 map tracks are referenced from the `MAPS` table in `index.html` (`musicUrl`). `bamboo-forest.mp3` is also the `MAPS.custom` default, so player-built maps get it unless they pick otherwise.
- The 11 calling-card tracks are referenced from `CALLING_CARDS[*].music` (the `worryslowed` "Moonlight" card is the one asset served from `../01-internal-code/src/Midnight_Ascent.mp3` instead).
- The 9 weapon SFX are the remote `AUDIO`/`SOUND` sample map (`handgunClick`, `handgunRelease`, `handgunMovement`, `shotgunPump`, `shotgunHardPump`, `shotgunLongPump`, `revolverSpin`, `laserShot`, `laserCannon`). Everything else in the game's audio is synthesised at runtime with the Web Audio API — no sample files.
- The 2 weapon PNGs are used for the HUD weapon name icon, the legendary drop banner, and the inventory/arsenal cards (`chara` → Real Knife, `slimesword` → Cid's Slime Sword).
- All 3D geometry, textures, particles and UI are generated procedurally in code (`index.html`) — there are no model, texture, shader or animation files beyond three.js itself.
