# External code

**This project has no external code.**

This generator contains no `{import:...}` statements. It does not depend on any other Perchance generator, plugin, npm package, CDN module, or vendored library. It is a *provider* of a plugin rather than a consumer: `imports/` in the workspace is empty, and the only link to another generator in the source is the documentation hyperlink to `perchance.org/number-set-plugin-example`.

See `../README.md` for the complete inventory.
