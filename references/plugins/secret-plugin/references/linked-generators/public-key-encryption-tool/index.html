Public Key Encryption Tool

You can use this interface to generate a 'linked' pair of encryption(public) and decryption(private) keys, and to encrypt and decrypt messages using those keys. Read the secret-plugin page to learn how this works.

This page uses the secret-plugin. If you want a very simple way for people to send you secret messages, make a copy of the send-me-a-secret-message page and swap out the public key for your own.

Note: If you want to encrypt an image, or any other non-text file, then you must convert it to a Data URL first. You can use the "Import File" button to do this automatically. To view a Data URL that you've decrypted (i.e. that someone has sent you), paste the whole thing into the URL/address/search bar of a new browser tab.
