Send Me a Secret Message

Read the secret-plugin page to learn how this works. Basically, if you submit a comment below in secret mode (notice the selector below the submit button), then I'm the only one who will be able to read it, since this page uses my "public key" to encrypt all submitted comments. You can seem my public key if you open the code editor. If you want to make your own page like this (so people can easily send you private messages), then you can open the editor and save this generator to create your own copy of it. Then just replace the publicKey = ... with your own public key which you generated using this tool.

Tip: If you create a copy of this generator, and you're logged in, then you can store your private key in the "Private Notes" textbox within your generator's settings menu. That way you don't have to go hunting through your notes app or whatever each time you want to check your private messages. You'll embed your public key in this generator's code after saving your own copy of it, so there's no need to store your public key in your notes.
Tip: The secret-plugin page explains how you could turn this into a shared private chat between multiple people. Basically, you just create a public/private key pair that's shared between all of you. I.e. you all know the private key, so you can all use the above 'decrypt comments' button.
But you each need to have your own copy of this 'send-me-a-secret-message' page first, so the person who creates the group's private key can securely share it with each group member. Then a member of the group creates an copy of this page for the group chat, and embeds the group's public key. If non-group members (i.e. people who don't have the private key) visit that page, they'll be able to comment, but they won't be able to read any of the other comments. Only the group members have the private key for that page, so only they are able to decrypt the comments.
Remember that, in general, you should never share your personal private key with anyone, but if you've created a key pair for a group of people, then it's fine to privately share both keys with those group members. Just remember that anyone who knows the private key will be able to decrypt all the comments. Everyone else can still add comments, but they can't decrypt/read them.
Caution: In order to use the above 'decrypt comments' button, you need to paste your private key. Each comment is then passed to the secret-plugin along with your private key in order to decrypt it. But you should be very careful about pasting your private key into generators that you didn't create yourself. You should definitely never paste an important private key into a generator/page just because they ask you to do that - they may be tricking to you steal your private key. If in doubt, check the official plugin list, perchance.org/plugins, and find the "secret-plugin", which is an official plugin. Then visit that page, and look at the linked demos. Use those official demos as a safe starting point. If you want a new official demo added, you can ask in the community forum.
Tip: When copying around public/private keys, you can double-click the key (or long-press it on mobile) as a fast way to select the whole thing. This works because keys never contain spaces or special characters, so the "double-click or long-press to select the whole word" shortcut that is common across operating systems works to select the whole key (i.e. the key is effectively treated as a single word). It's easier and less error-prone than clicking and dragging to highlight it.
Also remember that public keys always start with PUBLIC_ and end with _END_PUBLIC. And private keys always start with PRIVATE_ and end with _END_PRIVATE. So you can easily double-check that you got the whole thing after copy-pasting a key somewhere.
