# External code & resources

Reference copies of the external Perchance generators that the goto-plugin
documentation links to. None of these are runtime dependencies of goto-plugin
(whose import list is empty) - they are bundled so the package is complete.

- go-to-plugin -> external-code/go-to-plugin/  — Community-made companion plugin referenced in the docs.
- remember-plugin -> external-code/remember-plugin/  — Save/restore companion plugin referenced in the docs.
- goto-plugin-example -> examples/goto-plugin-example/  — Complex example.
- goto-plugin-example-with-audio -> examples/goto-plugin-example-with-audio/  — Grid world + audio example.
- goto-and-remember-plugins-example -> examples/goto-and-remember-plugins-example/  — goto + remember save/load example.
