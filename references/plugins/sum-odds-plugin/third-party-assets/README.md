# Third-party assets

None.

This generator references no images, audio, video, fonts, 3D models, animations, shaders,
prefabs, sprite sheets, tilemaps, UI resource files or JSON data files. There are no
hotlinked remote assets and no embedded data URLs.

The visual styling is entirely inline CSS inside the two <style> blocks of `index.html`
(`body`, `code`, `ul.dot-list li`, `pre.custom`, plus the platform's defaults).
