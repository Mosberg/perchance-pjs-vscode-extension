# text-to-image-plugin — Complete Source & Asset Package

**Generator name:** `text-to-image-plugin`
**Live page:** https://perchance.org/text-to-image-plugin
**Backend origin:** https://image-generation.perchance.org
**Packaged:** 2026-09-16

This archive is a byte-exact snapshot of everything this generator is made of: its own source,
the third-party code it loads at runtime, the media assets linked from its documentation, and a
manifest of every external service it talks to. Nothing here is summarized or truncated.

---

## 1. `internal-code/` — the generator's own source

| File | Size | Description |
|------|------|-------------|
| `main.pjs` | 37,978 B | **The entire plugin.** A Perchance-JS file consisting of one top-level `$output(data, opts) => …` function (the plugin entry point) written in plain JavaScript, followed by the example prompt lists. Implements: the prompt parser (`(key:::value)` inline options, plus a bracket-aware `negativePrompt` parser), input validation/sanity checks, default sizing (resolution → CSS width/height, old-browser `aspect-ratio` fallback), output `<iframe>` HTML generation, the lazy-load logic (two `IntersectionObserver`s + a `getBoundingClientRect` poll fallback), the public-gallery embed builder and its `postMessage` bridge, custom gallery buttons, and the optional `removeBackground` path (dynamic import of transformers.js + the `briaai/RMBG-1.4` model). Lines 751+ are the example prompt lists. |
| `index.html` | 21,121 B | **The documentation / landing page** (the `<body>` contents only — Perchance supplies the `<html>`/`<head>`/`<body>` wrapper). Contains all usage examples, the options/gallery/moderation/custom-button/advanced-usage docs, two live demos generated by `[$output(prompt)]`, the "you forked the plugin" warning banner, and the page's `<style>` block. |

## 5. `build-config/` — configuration & manifest

| File | Description |
|------|-------------|
| `manifest.json` | Machine-readable index of every file in this package: category, path, byte size, SHA-256. |

**There is no build pipeline.** Perchance generators are interpreted at runtime by the Perchance
engine — `main.pjs` is parsed and evaluated as-is, and `index.html` is injected into the page.
There is no bundler, transpiler, package manager, lockfile, or CI config in this project. The only
"config" surfaces are:

- The `$output(data, opts) => …` signature at the top of `main.pjs` — this is what makes the
  generator importable as a plugin, and it is where `generateImage`/`image` resolves to.
- `data`/`opts` option names parsed inside `main.pjs` (`prompt`, `seed`, `resolution`, `width`,
  `height`, `size`, `guidanceScale`, `negativePrompt`, `style`, `saveTitle`, `saveDescription`,
  `removeBackground`, `hideGalleryButtons`, `gallery`, `sort`, `timeRange`, `contentFilter`,
  `hideIfScoreIsBelow`, `defaultGalleryNames`, `bannedUsers`, `bannedPromptPhrases`,
  `bannedNegativePromptPhrases`, `customButton`, `customButton2`, `adaptiveHeight`,
  `forceColorScheme`, `verifyOnly`, `id`, `onFinish`).
- The hard-coded server origin `let serverOrigin = "https://image-generation.perchance.org";`.

## How the pieces fit together

```
index.html  ──(renders live demos with)──▶  [$output(prompt)]
       │                                         │
       │                                    main.pjs  ($output function)
       │                                         │
       └──(docs, <img> assets)──┐                ├─▶ builds <iframe class="…image-iframe">
                                │                │        src = image-generation.perchance.org/embed#<urlHash>
   third-party-assets/ ◀────────┘                │
                                                 ├─▶ builds <iframe class="…gallery">
                                                 │        src = image-generation.perchance.org/gallery?…
                                                 │
                                                 └─▶ (only if removeBackground)
                                                          import("cdn.jsdelivr.net/npm/@huggingface/transformers@3.3.3")
                                                          → briaai/RMBG-1.4 → onnxruntime-web .wasm
```
