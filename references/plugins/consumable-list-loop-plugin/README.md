# consumable-list-loop-plugin — complete source & asset package

Perchance generator: https://perchance.org/consumable-list-loop-plugin

A drop-in Perchance plugin that wraps a Perchance list so that, instead of
erroring out ("no more items in <list>") when a `consumableList` is exhausted,
it transparently re-fills ("shuffles") and keeps handing out items forever.

## Usage

```
consumableListLoop = {import:consumable-list-loop-plugin}
```

```
[cl = consumableListLoop(myList)]  [cl]  [cl] ...
```

## Dependencies

None. `main.pjs` declares **zero** `{import:...}` lines, so there are no
Perchance plugins, npm packages, CDNs, fonts, or third-party code of any kind.
The generator is fully self-contained: two source files, no externals.

## Runtime notes

- Everything runnable lives in `main.pjs`, exported via `$output(list) => ...`,
  whose return value is a `Proxy` around the caller's list.
- `index.html` is documentation-only (plus `<style>`), no scripts at all.
- No images, audio, models, shaders, animations, JSON data, or prefabs are
  referenced or generated by this project (verified: zero `<img>`, `<audio>`,
  `<video>`, `url(`, `fetch(`, or `{import:` references anywhere).
